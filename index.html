geelen.audio

Pareto Amp installer

Plug in the board over USB, pick Amped or Louder and a release, then flash. No extra apps on Chrome, Edge, Opera, or Firefox 151+. Safari cannot talk to serial ports — use Download instead.

A factory write at flash offset 0x0 erases NVS: Wi-Fi, EQ, presets, and the device name. To keep NVS, clone the matching tag and run task fw:flash.

1. Product

USB cannot tell Amped from Louder. An Amped image on a Louder board leaves EQ in software. Override the radios if the hint is wrong.

2. Version

3. Flash

ESP32 vs ESP32-S3 is detected after Connect. If this is an S3 in USB-audio mode, hold BOOT, tap RESET, release BOOT, then Connect.

This browser has no Web Serial. Web Serial needs HTTPS (or localhost).

In-browser flash needs Chrome, Edge, Opera, or Firefox 151+.
